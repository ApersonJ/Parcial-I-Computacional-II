1. Fenomenología y pregunta física

  • Mathieu: la rigidez se modula en el tiempo, ω0² + h cos(Ωt). Con Ω ≈ 2ω0 y h sobre un umbral, el equilibrio se vuelve inestable (resonancia paramétrica) [1].
  • Duffing: la rigidez cúbica βx³ frena el crecimiento y la amplitud se estabiliza.
  • Ruido blanco aditivo de intensidad σ: una trayectoria ya no caracteriza al sistema, hay que estudiar ensambles de realizaciones.

Preguntas: (1) ¿Euler-Maruyama o Heun? (2) ¿cómo evolucionan ⟨x⟩, Var[x] y P(x)? (3) ¿cómo depende la respuesta de σ, bajo y sobre el umbral? (4) ¿cómo separar ruido de dinámica determinista? (5) ¿qué revelan la autocorrelación y el espectro?

2. Modelo: variables y parámetros

Variables
  • Posición x y velocidad v = dx/dt
  • Proceso de Wiener Wt, con dW ≈ √Δt · η, η ~ N(0,1)
  • Ensamble de N realizaciones
Parámetros
  • δ: amortiguamiento; ω0: frecuencia natural
  • h, Ω: amplitud y frecuencia de la modulación
  • β: rigidez cúbica (β ≥ 0)
  • σ: intensidad del ruido

3. Ecuaciones del modelo

ẍ + δ ẋ + [ω0² + h cos(Ωt)] x + β x³ = σ ξ(t)

Ecuación estocástica de Itô:  dx = v dt,   dv = a(t, x, v) dt + σ dWt, con a = −δv − [ω0² + h cos(Ωt)]x − βx³.

Umbral paramétrico (primer orden, Ω ≈ 2ω0) [1]:

hc ≈ 2 δ ω0    (δ = 0,1, ω0 = 1 → hc ≈ 0,2)

Límite lineal (h = β = 0), solución exacta usada para validar [4]:

Var[x] = σ² / (2 δ ω0²)    Var[v] = σ² / (2 δ)

La ecuación es impar en x: si x(t) es solución, −x(t) también.

4. Método: esquemas estocásticos

Euler-Maruyama (orden fuerte 1 con ruido aditivo [2]):

xn+1 = xn + Δt vn,   vn+1 = vn + an Δt + σ ΔWn

Heun estocástico (predictor-corrector, mismo ΔW en ambas etapas):

ṽ = vn + an Δt + σ ΔWn
vn+1 = vn + ½Δt [an + ã] + σ ΔWn
  • El ruido es aditivo: Itô y Stratonovich coinciden, así que Heun es válido.
  • Milstein no se implementó: su corrección depende de la derivada del coeficiente de ruido; aquí es constante, y coincide con Euler-Maruyama [2].
  • RK4 solo como control con σ = 0.
  • t = i·Δt para no acumular redondeo en cos(Ωt).

5. Arquitectura del programa (C++, POO)

  • Clase Generador_Ruido (Ruido.h / .cpp): std::mt19937_64 y std::normal_distribution; Inicie(semilla), calcularIncrementoWiener(dt).
  • Clase Osc_Mathieu_Duffing (MathieuDuffing.h / .cpp): estado (x, v); calcularAceleracion(), MuevaseEulerMaruyama(), MuevaseHeun(), MuevaseRK4().
  • El ruido no vive en el oscilador: ΔW llega como argumento, y dos esquemas pueden recibir el mismo ruido.
  • punto3.cpp: ejecutarPunto3(), ensamble con sumas de x, x², v, v² por instante; guarda momentos.dat, x_final.dat y parametros.txt (con la semilla).
  • experimentos.cpp (make exp3): validación, convergencia, barrido en σ, estroboscópico y espectro.

7. Simulación principal: realizaciones

  • h = 0,5 (sobre el umbral), σ = 0,2, Heun, Δt = 0,01, N = 200.
  • Todas parten de x0 = 0,5, v0 = 0; el ruido las separa rápidamente.
  • La media ⟨x⟩ se aplana: para t > 60, |⟨x⟩| ≤ 0,076, compatible con cero (error estándar ≈ 0,03).

8. Momentos del ensamble

  • Var[x] entra en régimen estacionario hacia t ≈ 22.
  • No es constante: oscila entre 0,086 y 0,312 con período 3,14 ± 0,13, el del forzamiento (T = π). Promedio (t ≥ 100): 0,186.
  • Con fase uniforme la varianza sería constante; oscila porque la fase queda fijada por el forzamiento (dos fases, x y −x).

9. Distribución P(x, tmáx)

  • Media 0,014 ± 0,036; desviación estándar 0,507; rango [−1,07; 1,12].
  • 48 % de las realizaciones con x > 0: se conserva la simetría x ↔ −x.
  • Curtosis en exceso −0,86 (gaussiana: 0; fase aleatoria: −1,5): compatible con amplitud casi fija más ruido.
  • Con N = 200 en 40 barras, el histograma es ruidoso.

11. Convergencia fuerte (3b)

  • Mismo camino browniano fino (Δtf = T/8192); referencia con Heun.
  • Orden observado: Euler-Maruyama 1,00–1,03; Heun 0,9–1,2. Ajuste log-log: 1,01 y 1,02.
  • Ambos tienen orden fuerte ≈ 1; Heun no gana en el orden sino en la constante: error 6 a 7 veces menor.
  • La referencia también es Heun; puede sesgar levemente su error a la baja.

12. Dependencia con la intensidad del ruido (3c)

  • Bajo el umbral (h = 0,1): sin ruido decae a 0; con ruido, ⟨x²⟩ crece de forma monótona, aprox. como σ².
  • Sobre el umbral (h = 0,5): parte de 0,152 (amplitud ≈ 0,55); no es monótona: baja a 0,126 en σ = 0,1 y sube a 0,304 en σ = 0,3.
  • Cinco semillas en σ = 0,1: 0,1207 ± 0,0015. La caída (≈ 17 %) supera esa dispersión; su causa no se investigó.

13. Ruido frente a determinismo (3d)

  • σ = 0: dos puntos, (∓0,1103; ±0,5805): respuesta de período 2T con x(t + T) = −x(t).
  • σ = 0,05: nubes alrededor de cada punto (489 valores distintos de 1500).
  • σ = 0,2: nubes anchas que se solapan (850 valores distintos).
  • Con σ = 0 la dinámica es regular: la irregularidad con σ > 0 se debe al ruido, no a caos determinista.

15. Conclusiones

  • El código reproduce el límite lineal exacto: Heun da Var[x] = 0,25 dentro de ≈ 2 %; Euler-Maruyama tiene sesgo de +4 % a +70 %.
  • Ambos esquemas tienen orden fuerte ≈ 1; Milstein coincide con Euler-Maruyama. Heun, con error 6–7 veces menor, se usó para la física.
  • Con h = 0,5 y σ = 0,2, ⟨x⟩ ≈ 0 y Var[x] oscila con el período del forzamiento (0,086–0,312).
  • Bajo el umbral, ⟨x²⟩ ~ σ²; sobre el umbral, cae antes de crecer (mecanismo sin explicar).
  • El mapa estroboscópico, la autocorrelación y el espectro distinguen los dos regímenes.
  • Limitaciones: un solo juego de parámetros y dos valores de h; no se midió la tasa de salto entre fases.
